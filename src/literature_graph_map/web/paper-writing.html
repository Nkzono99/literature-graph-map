証拠を示す順に章を組む

機構を提案し、対照実験で絞る

粒子の離脱を引き起こす機構を提案するWang 2016は、序論の次に粒子間の空隙へ電子がたまる帯電モデルを置く。実験結果の節で照射条件を変えた粒子の動きと、モデルを模したプローブの測定を示し、考察では計測した跳躍を軌道モデルと比べて月面へ外挿する。モデルを先に読むと、粒子の動きとプローブ電位がそれぞれ何を支えるか追える。原著 §§2–4{% if paper_links.P000009 %} ／ 文献マップの要点（Wang 2016）{% endif %}

計算の前提を示し、基準との差を調べる

飛行中の帯電が軌道をどこまで変えるかを問うYeo 2021は、序論で離脱時の負電荷を説明し、計算の節で初速や周囲の環境を定める。結果では帯電と軌道の例を出し、粒径や重力を変えた計算を、重力だけの基準と比べる。粒子が飛び始める条件を先に共有することで、計算で変えた量と、高度差を読む基準をたどれる。原著 §§1–4、図1–3

測れる信号を定義し、観測が許す上限を示す

個別には捉えられない微粒子を探すSzalay 2015は、序論で粒径を定め、装置の節で粒子が作る信号と背景の差し引き方を説明する。観測の節で実測電流と既往研究から予測した電流を比較し、残差電流から密度の上限を求める。装置の節を読むと、背景が残る状況で上限を出せる理由が分かる。原著 §§1–4、図3–4{% if paper_links.P000039 %} ／ 文献マップの要点（Szalay 2015）{% endif %}

八つの文が、方法を選ぶ理由を作る

Szalay 2015の装置説明は、最初の段落で「なぜ一粒ずつ数える方法を使えないか」に答える。各文の内容を原文の順に要約した。原著 §2 第1段落

  1. 背景。 探査機の打ち上げ日と月周回軌道に入った日を記す。
  2. 計器の紹介。 月の周囲でダストの粒径・密度分布を調べる検出器を示す。
  3. 信号の発生。 粒子が標的に高速で衝突するとプラズマが生じる。
  4. 信号の読み取り。 そのうち正イオンを検出器へ導く。
  5. 量への換算。 粒子の質量と衝突速度から信号の大きさを求める較正式を置く。
  6. 判定の基準。 個別検出には約3,000電子分の電荷が必要だと示す。
  7. 対象との比較。 半径0.1 µmの粒子について、密度と衝突速度を仮定し、信号を約100電子分と見積もる。
  8. 方法への接続。 想定した粒子は閾値を下回るため、別の探し方が要ると結ぶ。次の段落で電荷を積算する方法を説明する。

同じ段落でも、日付は探査機の紹介に使え、約100と約3,000の比較は測定方法を選ぶ根拠になる。論証を保って縮めるなら、日付を省き、信号を得る仕組みは一文にまとめられる。二つの値と比較結果は残す。較正式は後段の密度換算にもつながるため、概説では参照に縮めても、解析を再現するための方法欄では保持する。原著 §3、密度と電流の換算

本文に残すかを役割で決める

外したときに困ることから判断する

  • 本文に残す。 結論を支える比較ができなくなる。適用範囲が変わって読める。
  • 参照できる場所に置く。 検算・再現・再解析に要る。方法欄、表、補足資料から選ぶ。
  • 一文にまとめる。 読者が背景を思い出したり、次の話題に移ったりする助けになる。
  • 省く。 外しても論旨が追え、同じ情報を検証できる。

段落は一つの問いに答える

段落ごとに「何と比べたか」「この差をどう説明するか」など、読者がそこで知りたいことを一つ書き出す。文を足すのは、問いを定める、根拠を出す、根拠から解釈への筋道を示す、適用範囲を限る、次の推論に要る前提を渡すとき。似た文が並んだら役割を確かめ、同じ役割ならまとめる。新しい比較や別の説明を扱うときは段落を分ける。

数値は、比較・判定・再現に使うものを選ぶ

主結果の大きさ、境界となる値、比較を成り立たせる条件は、読み手が判断する箇所の近くに置く。値の意味が変わる単位、対象、基準、不確かさも添える。Szalay 2015の密度上限は約100 m−3。月が太陽風中にあるときの明け方側の明暗境界、高度3 kmで、粒子半径は0.1 µmを想定している。残差電流をすべてダストに割り当てて換算した上限だと書けば、測った量と換算した量の関係が伝わる。原著 §4、図4

図には関係を、表には照合する値を置く

Yeo 2021の図3上段は到達高度を示し、下段は重力だけの場合との高度差を百分率で示す。下段があると、上段では線が重なる範囲でも差の向きと大きさを読める。本文は、弱い重力のもとで粒子からの光電子放出が強いと、基準より高く飛ぶ場合があることを拾い、その理由を説明する。キャプションには初期電位、系列の条件、差を計算した基準を残す。原著 §3、図3（p. 4）

表は条件をまたいで正確な値を照合するときに使う。Wang 2016の表1では、三つの照射条件の推定電荷や力を同じ行で比べられる。粒子を球とした凝集力の推定など、値の読み方を左右する仮定は表注に置く。原著 §3.2、表1（p. 6108）

主張の条件は本文に、検証の詳細は参照先に置く

条件を省くと結論が変わって読める場合は、結果と同じ文か段落に残す。再現に必要な設定や計算過程は方法欄、表、補足資料に置き、本文からたどれるようにする。既報の手順を使った場合は、何を使い、どこを変えたかを本文に示して原典を参照する。判断にも検証にも使わない背景は、段落の流れに必要な分だけ残す。

AI草稿は役割を見て削る

対照条件と解釈の限界を一緒に残す

Wang 2016の比較実験をもとに、説明を足しすぎた草稿を作り、比較が追える長さに推敲した。原著 §3.1、図2b・3a（pp. 6105–6106）

推敲前　粒子の運動を評価するには、粒子を取り巻く環境に注意を払う必要がある。本研究では二種類のプラズマ条件を設定し、それぞれでダストの挙動を比較した。実験の結果、表面付近の電場は両条件でおおむね同程度であったが、電子ビームを加えた場合にのみ粒子の跳躍が見られた。この結果は、条件設定が結果の解釈において重要であることを示している。

推敲後　熱プラズマ単独の条件と、電子ビームを併用した条件で、表面付近の鉛直電場はいずれも約16 V/cmだった。粒子の跳躍はビームを併用した条件でのみ観察された。高さ方向の電場分布には差があった（図2b）。

環境や条件の重要性を述べる一般論を外し、読者が比較に使える電場の大きさを示した。どこまで条件がそろったかも書いたので、この比較が支える解釈の範囲をたどれる。

新しい文献から判断例を増やす

章は、各節が答える問いを一行ずつ並べ、前の節の何を次で使うかを書く。細部は「原著の版と場所／要素／役割／外すと何が困るか／自分の原稿での置き場所」を一件ずつ記録する。
